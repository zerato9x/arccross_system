# ARCCROSS ChatGPT Project Pack

This folder describes the non-code knowledge base to use in a normal ChatGPT
Project for ongoing lore and gameplay discussion.

## Suggested Project name

`ARCCROSS — Lore & Game Design`

## Files to add to the ChatGPT Project

Upload `PROJECT_INSTRUCTIONS.md` first, then these existing repository documents:

1. `READMEs/WORLD_TIMELINE_CODEX.md`
2. `READMEs/CANONICAL_WORLD_SPECIFICATION.md`
3. `READMEs/GLOSSARY.md`
4. `READMEs/design/CENTRAL_CORE_CAMPAIGN_OVERHAUL.md`
5. `READMEs/design/MACRO_WORLD_OVERHAUL.md`
6. `READMEs/design/TURN_BASED_COMBAT_OVERHAUL.md`
7. `READMEs/design/VISUAL_DIRECTION.md`
8. `READMEs/design/HEX_DRESSING_TEMPLATES.md`

These files cover canonical chronology, hidden setting truth, terminology, the
current campaign scope, gameplay direction, visual language, and environmental
composition. They intentionally exclude source code, architecture documents,
tests, asset manifests, and implementation changelogs.

## Recommended first message

> Read the Project sources and give me a compact creative-state summary split into
> confirmed canon, current playable campaign, open questions, and contradictions.
> Do not invent resolutions. From then on, treat proposals as non-canon until I
> explicitly approve them.

## Maintenance rule

When repository canon changes, replace the affected Project source rather than
adding another dated copy. Duplicate bibles are how continuity errors acquire
tenure.
