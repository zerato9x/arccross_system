# Minimal Godot Demo

A ready-to-run demo project showcasing all 6 shaders.

## How to Run
1. Open this folder in Godot 4.2+
2. Press F5

The demo scene will launch automatically with all 6 effects visible:
- Outline
- Dissolve Burn
- Heat Distortion
- Drop Shadow
- Flash Tint
- Radial Wipe

## Files
- `project.godot` — demo project
- `effects_showcase.tscn` — showcase scene with all effects
- `effects_showcase.gd` — runtime animation script
- `shaders/` — shader files used by the demo

## Customizing
Open `effects_showcase.tscn` in the editor and modify shader parameters in the Inspector to experiment with different looks.
